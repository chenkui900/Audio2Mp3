#  欢迎下载使用Audio2Mp3转换工具
##  *本人不会编程*
<p>自己做的一个多线程音频文件转MP3工具，需要安装python3.12以上版本。</p>
<p>Audio2MP3.exe是不带FFMpeg的版本。</p>
<p>Audio2Mp3_with_FFMpeg.exe是自带FFmpef的版本。</p>
<p>根据需要选择下载。</p>
<p>程序第一次运行时，会自动下载python插件，需要较长时间。</p>
<p></p>

##   开发背景
<p>最开始知识简单的想将本地从youtube上下载小说m4u文件转换成mp3文件缩小文件体积，方便离线播放。但是发现下载的m4u文件波特率比较高，体积比较大，因此想能够在不影响效果的前提下转换成体积比较小的文件。最开始是使用PowerShell脚本转换，也实现了大部分功能。</p>
<p>后来想着用AI做一个程序，方便使用。于是就有了这个程序。这个程序代码我没有敲一个字母，我只提出我的需求，全部是用AI自动生成的。</p>
